Project Overview

Asisten Perekap Kegiatan (ASEK) is an automated WhatsApp bot specifically engineered to streamline the performance reporting process (Capaian SKP) for Civil Servants (ASN). Built on the n8n automation infrastructure, the system intelligently parses user message captions using regular expressions to instantly extract activity dates, keywords, and descriptions. It seamlessly integrates with the Evolution API and Nextcloud to automatically download media, construct organized folders, upload operational evidence, and generate public sharing links, simultaneously logging all data into a Google Sheets database. This creates a ready-to-use, chronologically organized archive that completely eliminates manual file uploads and repetitive data entry, ensuring performance reporting is effortless and accurate.

Key Challenges Addressed

  • Rigorous SKP Reporting Requirements: Civil Servants are required to submit periodic performance reports complete with activity dates, descriptions, and verifiable proof links (bukti dukung)—a tedious process to compile manually at the end of a cycle.
  • Impractical Real-Time Logging: Inputting activity details directly into official administrative applications immediately after task completion is often unfeasible due to time constraints and field responsibilities.
  • Tedious Manual Workarounds: Creating a personal backup tracker on spreadsheets requires a highly repetitive, multi-step process: manually creating cloud folders, uploading evidence, generating sharing links, and copy-pasting those links into the sheet one by one.

Core Features & Solutions

Instant WhatsApp-to-Sheet Logging

ASEK eliminates the need for immediate data entry into official apps. Users can simply send activity photos and descriptions via a WhatsApp message from anywhere. The system’s parsing engine instantly extracts the exact dates and descriptions, logging them directly into a Google Sheets tracker structured specifically for SKP formats.

Automated Evidence Archiving & Link Generation

To eliminate the tedious manual upload process, the bot automatically downloads sent media, organizes them into dynamically named Nextcloud folders, and instantly generates public sharing links. These evidence links are automatically inserted into the spreadsheet alongside the activity data in a single, seamless flow.

Ready-to-Submit SKP Database

With all data and evidence links continuously recorded and structured chronologically in the background, the system acts as a fully prepared digital logbook. At the end of the reporting period, users can effortlessly copy the complete, formatted data to fulfill their Capaian SKP requirements in mere seconds.
